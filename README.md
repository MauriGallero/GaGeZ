# GaGeZ 🎶

Página web del duo GaGez - Mauri Gallero y Flo Gerez. Duo de Moreno, Buenos Aires.

**Live Demo:** https://maurigallero.github.io/GaGeZ/

### Sobre el proyecto
Landing simple para compartir nuestra música, ensayos y covers. Hice la web desde cero con HTML y CSS para practicar.

### Qué incluye
- Foto del duo
- Links a ensayos en Instagram y YouTube
- Reproductor de audio con cover de "La Bifurcada"

### Tecnologías
- HTML5 (audio, estructura semántica)
- CSS3 (responsive, Google Fonts)
- GitHub Pages para deploy
